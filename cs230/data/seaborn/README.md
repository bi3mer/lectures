# Seaborn Sample Data

[Visualization](../../lectures/16-visualization.html) reads these two files from this folder on the course site, so its slides keep working if the originals in seaborn-data change or move.

Both files are copied unchanged from the [seaborn-data](https://github.com/mwaskom/seaborn-data) repository by Michael Waskom, which holds the sample data for the [seaborn](https://seaborn.pydata.org/) charting library. That repository has no license file, so the credits below follow the sources its README lists.

## `flights.csv`

Monthly totals of international airline passengers, in thousands, from 1949 to 1960: 144 rows of `year`, `month`, and `passengers`.

The data is R's [`AirPassengers`](https://stat.ethz.ch/R-manual/R-devel/library/datasets/html/AirPassengers.html) series, from Box, G. E. P., Jenkins, G. M., and Reinsel, G. C. (1994), *Time Series Analysis: Forecasting and Control*, third edition, Prentice Hall.

## `tips.csv`

One waiter's tips over a few months at one restaurant: 244 rows, one for each table, with the bill, the tip, the day, the meal, and the size of the party.

The data comes from the [reshape2](https://rdrr.io/cran/reshape2/man/tips.html) package for R by Hadley Wickham, released under the MIT license. Its original source is Bryant, P. G. and Smith, M. (1995), *Practical Data Analysis: Case Studies in Business Statistics*, Richard D. Irwin Publishing.
